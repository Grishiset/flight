# ✈️ Трекер летних цен на авиабилеты

Самостоятельное приложение. Каждые 4 часа оно проверяет билеты туда-обратно из Москвы в Сеул, Токио, Нью-Йорк, Лос-Анджелес и Новую Зеландию на лето 2027 и присылает уведомление в Telegram, если цена ниже обычного. Работает на GitHub Actions бесплатно, компьютер можно выключать. Всё найденное, с историей цен, видно на сайте в GitHub Pages.

## Откуда берутся цены

| Источник | Что даёт | Нужно |
|---|---|---|
| **Aviasales** (официальный API Travelpayouts) | Кэш поисков Aviasales за последние 2–7 дней: сотни агентств и авиакомпаний, включая Trip.com и китайских перевозчиков | бесплатный токен |
| **Google Flights** (через SerpAPI) | Тарифы почти всех авиакомпаний, в том числе при покупке напрямую (Etihad, Qatar, Turkish, Royal Air Maroc…), и «обычный» диапазон цен от Google | бесплатный ключ, 250 поисков/мес |
| **Etihad** (etihad.com) | Тарифы с собственных страниц Etihad, которые видели пользователи сайта. Переводятся в рубли по курсу ЦБ | ничего |
| **Самокатус** | Самые дешёвые билеты и распродажи, которые они публикуют | ничего |

Каждый источник независим: если один упал, остальные работают. Состояние источников видно на сайте.

## Когда приходит уведомление

Берётся самый дешёвый летний билет по направлению: и вылет, и возвращение с 1 июня по 31 августа, поездка 5–30 дней. Уведомление приходит, если выполнено хотя бы одно:

1. цена **ниже порога** из `config.yaml` (порог — «хорошая цена» по прошлым распродажам);
2. цена **на 15% ниже медианы** собственной истории за 30 дней;
3. цена **ниже обычного диапазона Google Flights**.

Повторное уведомление по тому же направлению приходит, только если цена упала ещё на 1000 ₽ или с прошлого прошла неделя. По понедельникам приходит **сводка** по всем направлениям. Если все источники не отвечают 3 запуска подряд, придёт **предупреждение**.

## Настройка (≈15 минут, один раз)

### 1. Репозиторий

1. Создай на GitHub **публичный** репозиторий, например `flight-tracker`: New repository → Public → Create. Публичный нужен, чтобы GitHub Pages и минуты Actions были бесплатными. Ключи и токены хранятся в секретах, их никто не увидит. В открытом виде будут только цены.
2. Загрузи туда все файлы из этого архива: «Add file → Upload files», перетащи содержимое папки целиком, включая скрытую папку `.github`. Или через git:
   ```bash
   cd flight-tracker
   git init && git add . && git commit -m "Трекер билетов"
   git branch -M main
   git remote add origin https://github.com/Grishiset/flight.git
   git push -u origin main
   ```
   > Если загружаешь через браузер и папка `.github` не подхватилась, создай файл вручную: «Add file → Create new file», имя `.github/workflows/track.yml`, вставь содержимое.

### 2. Telegram-бот

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → получишь **токен** вида `123456:ABC…`.
2. Открой своего бота и нажми **Start** (без этого бот не сможет тебе писать).
3. Узнай свой **chat id**: открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":123456789`. Другой способ — написать [@userinfobot](https://t.me/userinfobot).

### 3. Ключи источников

- **Travelpayouts (Aviasales)**: зарегистрируйся на [travelpayouts.com](https://www.travelpayouts.com/), подключи программу Aviasales. Токен — в «Профиль → API-токен».
- **SerpAPI (Google Flights)**: зарегистрируйся на [serpapi.com](https://serpapi.com/users/sign_up). Ключ — в [Dashboard](https://serpapi.com/manage-api-key). Бесплатно 250 поисков в месяц, трекер тратит около 180. Можно пропустить: тогда Google Flights просто не будет.

### 4. Секреты в GitHub

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Создай:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | твой chat id |
| `TRAVELPAYOUTS_TOKEN` | токен Travelpayouts |
| `SERPAPI_KEY` | ключ SerpAPI (необязательно) |

### 5. Сайт и первый запуск

1. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Вкладка **Actions** → если просит, нажми «I understand… enable workflows».
3. Слева выбери **«Проверка цен на билеты» → Run workflow → Run workflow**. Через 3–5 минут:
   - на сайте `https://grishiset.github.io/flight/` появятся цены (ссылка есть и в логе запуска, шаг deploy);
   - если сегодня понедельник, в Telegram придёт сводка. В другие дни сообщение приходит, только когда найдена выгодная цена.

Дальше всё работает само каждые 4 часа. С телефона запустить проверку вручную можно в приложении GitHub: Actions → Run workflow.

## Как поменять настройки

Все настройки лежат в `config.yaml`. Его можно править прямо на GitHub: открыть файл → карандаш → Commit.

- **Пороги** — `threshold` у каждого направления.
- **Даты** — `window` (начало и конец лета, минимальная и максимальная длина поездки).
- **Новое направление** — скопируй блок в `routes`: нужны `id`, `name`, `threshold`, `city` (код города IATA) и `airports`. Страницы Etihad и Самокатуса — по образцу соседних (необязательно).
- **Частота проверок** — строка `cron` в `.github/workflows/track.yml` (время UTC).
- **Сводка** — `alerts.digest_weekday` (0 — понедельник, `null` — выключить).

## Запуск у себя на компьютере (для отладки)

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt pytest
python -m playwright install chromium
export TELEGRAM_BOT_TOKEN=… TELEGRAM_CHAT_ID=… TRAVELPAYOUTS_TOKEN=…   # Windows: set …

python -m tracker test-telegram          # проверить бота
python -m tracker run --dry-run          # проверить цены, ничего не сохраняя и не отправляя
python -m tracker run --only etihad      # один источник
python -m tracker show                   # последний результат
python -m pytest                         # тесты
```

## Что важно знать

- **Цены агрегаторов — это кэш.** Aviasales хранит цены, найденные пользователями за последние 2–7 дней. Etihad показывает тарифы, которые недавно видели на его сайте. Перед покупкой открой билет по ссылке и проверь цену.
- **Летние даты 2027 появляются постепенно.** Пока их мало кто ищет, у некоторых направлений будет «летних билетов пока нет». Это нормально.
- **Etihad и Самокатус** могут не пускать серверы GitHub, они находятся в США. Тогда трекер открывает страницу в настоящем браузере (Chromium). Если и это не помогло, источник будет помечен на сайте как ошибочный, а остальные продолжат работать.
- **Kupibilet, OneTwoTrip, Trip.com** напрямую не опрашиваются: у них нет открытого API, и они защищены от автоматических запросов. Их цены по большей части попадают в Aviasales, а цены авиакомпаний — в Google Flights.
- GitHub отключает расписание в репозиториях без активности 60 дней. Трекер коммитит историю цен при каждом запуске, так что это не должно случиться. Если всё же придёт письмо от GitHub, нажми в нём «Enable».

## Устройство

```
config.yaml                 настройки
tracker/
  app.py                    один запуск: сбор → анализ → уведомления → сохранение → сайт
  providers/                источники: travelpayouts, google_flights, etihad, samokatus
  analyze.py                фильтр по датам, медиана истории, кому слать уведомление
  notify.py                 Telegram
  site.py, site_template/   сайт для GitHub Pages
data/                       история цен и состояние (коммитится автоматически)
.github/workflows/          расписание (track.yml) и тесты (tests.yml)
tests/                      тесты парсеров и логики уведомлений
```
