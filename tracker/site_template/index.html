    Как это работает

    Каждые 4 часа GitHub Actions запускает трекер. Он опрашивает Aviasales (через официальный API Travelpayouts), Google Flights (через SerpAPI), страницы тарифов Etihad и Самокатус, оставляет только билеты туда-обратно, где и вылет, и возвращение попадают в окно лета, и выбирает самый дешёвый по каждому направлению.

    Уведомление в Telegram приходит, если цена ниже порога из config.yaml, заметно ниже медианы собственной истории или ниже «обычного» диапазона Google Flights. Повторно о том же направлении — только если цена упала ещё сильнее или прошла неделя.

    Цены у агрегаторов — кэш недавних поисков, у Etihad — тарифы, которые видели пользователи сайта, переведённые в рубли по курсу ЦБ. Перед покупкой открывай билет по ссылке и проверяй цену.
